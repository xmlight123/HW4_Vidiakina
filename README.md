# HW4_Vidiakina
Материалом для практики послужит текст из книги, содержащей переписку писателя-драматурга Николая Эрдмана и его возлюбленной Ангелиной Степановой, актрисы МХАТа. В тексте есть сами письма (с 1928 по 1935 гг.), а также фрагменты из воспоминаний Степановой (опубликованных в 1995 году и относящихся к этому периоду).

## Структура датасета

| Столбец | Содержание |
|---|---|
| `date` | Дата письма в формате `YYYY-MM-DD`, если её удалось определить. |
| `author` | Автор письма: `Эрдман` или `Степанова`. |
| `text` | Текст письма после очистки. |
| `lemmatized_text` | Слова письма, приведённые к начальной форме, без знаков препинания. |
| `word_count` | Количество слов после токенизации. |

В текущей версии CSV — **72 записи**, из них **13 без полной даты**. Авторы указаны для всех записей, но автоматическое определение требует проверки в неоднозначных случаях.

## Как обрабатывался текст
1. Прочитала `erdman.txt` в Python.
2. Разделила текст на блоки с помощью `re.split()` по разделителю `* * *`.
3. Отделила письма от фрагментов воспоминаний.
4. Исключила отдельно выделенные телеграммы и обращение к начальнику строительства.
5. Искала даты в строках писем; разбирала несколько способов записи дат с помощью регулярных выражений и строковых методов.
6. Определяла авторов по подписям и сведениям об адресате, отдельные случаи проверяла вручную.
7. Удалила сноски вида `[23]`, заменила переносы строк и лишние пробелы.
8. Разделила тексты на слова с помощью `razdel`, а затем привела слова к начальной форме с помощью `pymorphy3`.
9. Создала датафрейм `pandas`, проверила его структуру и сохранила результат в CSV.

## Как обрабатывались пропуски

Даты в исходном тексте записаны по-разному: иногда указан полный день, месяц и год, иногда год отсутствует, а иногда нет точной даты. Если год не указан, в коде он восстанавливается по предыдущим письмам с учётом перехода на следующий год. Это **предположение по хронологии**, поэтому такие случаи могут требовать проверки. Если точную дату определить не получилось, в `date` оставлена пустая строка. Неполные даты (например, только месяц) в текущем CSV не сохранены.

Авторы определялись автоматически по подписям и адресату; несколько случаев без обычной подписи были проверены отдельно.
